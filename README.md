# NEXUS AI V3 — GitHub Pages edition

نسخه کاملاً استاتیک NEXUS AI؛ بدون Node.js، بک‌اند، Worker یا هاست جداگانه.

## انتشار روی GitHub Pages

1. در GitHub یک repository جدید بساز (مثلاً `nexus-ai`).
2. فایل `index.html` را در ریشه repository آپلود کن و commit بزن.
3. وارد **Settings → Pages** شو.
4. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کن.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذار و Save کن.
6. بعد از چند دقیقه، آدرس `https://USERNAME.github.io/nexus-ai/` فعال می‌شود.

## فعال‌کردن چت هوش مصنوعی

1. از بخش Settings اپ، کلید OpenAI API را وارد کن.
2. مدل پیش‌فرض `gpt-4.1-mini` است؛ در صورت نیاز می‌توانی نام مدل دیگری را وارد کنی.
3. روی «ذخیره تنظیمات اتصال» بزن و به بخش دستیار برگرد.

این نسخه درخواست‌ها را مستقیماً از مرورگر به `https://api.openai.com/v1/responses` می‌فرستد. کلید فقط در `sessionStorage` همان تب ذخیره می‌شود و در repository قرار نمی‌گیرد. با بستن تب، کلید پاک می‌شود.

**محدودیت مهم:** این اتصال مستقیم فقط برای تست شخصی است. کلید در مرورگر قابل مشاهده است و کاربر کنترل کامل روی آن ندارد؛ آن را در دستگاه مشترک وارد نکن، با کسی به اشتراک نگذار و هرگز آن را در کد commit نکن. API مصرف و هزینه جداگانه از اشتراک ChatGPT دارد. اگر CORS یا سیاست حساب مانع درخواست مرورگر شود، برای اتصال آنلاین باید بعداً یک واسط سمت سرور اضافه شود؛ خود GitHub Pages بک‌اند اجرا نمی‌کند.
